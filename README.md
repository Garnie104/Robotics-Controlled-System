## 📑 Rincian Konten

### 1. `Assesment 1`
* **Topik:** *Recent progress and challenges of key technologies in robotic assembly* (Longhui Qin).
* **Fokus:** Persepsi sensor (visual 2D/3D, F/T, taktil, fusi multimodal), jenis *end-effector*, strategi kontrol kontak, pembelajaran robot (*LfD, RL, Sim2Real*), dan hasil Focus Group Discussion (FGD).

### 2. `Assesment 2`
* **Topik:** *In-Depth Review of Advanced Control Strategies and Cutting-Edge Trends in Robot Manipulators* (Sherif I. Abdelmaksoud, dkk. - IEEE Access 2024).
* **Fokus:** Pemodelan dinamika tautan (rigid, flexible, rigid-flexible, multi-link), 7 kerumitan matematis manipulator, metode kontrol modern (*SMC, LQR, ZNN, Observer-based, RL*), dan identifikasi *research gap*.
